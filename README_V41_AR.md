# ISLAND SURVIVAL V41

نسخة بنية Multiplayer جديدة تعتمد حسابات المستخدمين والردهـات الديناميكية.

## التشغيل
```bash
npm start
```
المنفذ الافتراضي 8080، ومسار WebSocket هو `/ws`.

## متغيرات البيئة
- `PORT`: منفذ HTTP/WebSocket، افتراضي 8080.
- `MAX_PLAYERS`: السعة الافتراضية لكل ردهة، افتراضي 20.
- `MAX_LOBBIES`: الحد التشغيلي للردهـات، افتراضي 10000.

## تخزين البيانات
تُنشأ ملفات `data/accounts.json`, `data/lobbies.json`, `data/worlds.json`, `data/players.json` تلقائيًا. اربط تخزينًا دائمًا في بيئة الاستضافة؛ وإلا قد تضيع البيانات عند استبدال الحاوية.

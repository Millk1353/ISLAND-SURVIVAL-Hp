# ISLAND SURVIVAL V46

لعبة بقاء ثنائية الأبعاد بواجهة عربية، عوالم محلية محفوظة، وسيرفرات جماعية عبر WebSocket. لا يوجد تسجيل دخول؛ اللاعب يدخل كضيف بمعرّف جهاز محلي.

## التشغيل
- Node.js 18 أو أحدث.
- `npm start` لتشغيل السيرفر.
- `npm run check` لفحص صياغة السيرفر والواجهة.
- `npm test` لاختبار تكامل السيرفر محليًا.

## متغيرات البيئة
- `PORT`: المنفذ، الافتراضي 8080.
- `DATA_DIR`: مجلد البيانات الدائمة، الافتراضي `./data`.
- `MAX_PLAYERS`: السعة الافتراضية لكل ردهة، الافتراضي 20.
- `MAX_CONNECTIONS`: أقصى اتصالات WebSocket، الافتراضي 250.
- `MAX_LOBBIES`: أقصى عدد ردهات، الافتراضي 10000.
- `ADMIN_API_KEY`: مطلوب لإدارة إنشاء الردهـات عبر `POST /api/admin/lobbies`.

## نقاط الخدمة
- `GET /api/health` حالة السيرفر والسعة والذاكرة.
- `GET /api/lobbies` قائمة الردهـات العامة.
- WebSocket: `/ws`.

يجب تشغيل الموقع والسيرفر على نفس النطاق أو ضبط عنوان WebSocket من صفحة السيرفرات. الاستضافة يجب أن تدعم WebSocket ويفضل استخدام HTTPS/WSS. اربط `DATA_DIR` بوحدة تخزين دائمة قبل النشر.

## تنبيه مهم
معرّف الضيف محفوظ في Local Storage، لذلك لا يمكن استرجاع هوية الضيف إذا تم مسح بيانات المتصفح أو الانتقال إلى جهاز آخر. لا تستخدم معرّف الضيف كوسيلة مصادقة لحسابات حساسة.

راجع `CHANGELOG_V46_AR.md` و`TEST_REPORT_V46_AR.md` للتغييرات والاختبارات.

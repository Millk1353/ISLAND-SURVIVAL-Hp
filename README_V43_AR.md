# ISLAND SURVIVAL V43

## نظام الردهـات التلقائي
- يبدأ النظام تلقائيًا بإنشاء الردهة `001` إذا لم توجد ردهات محفوظة.
- عند امتلاء كل الردهـات العامة، ينشئ الخادم تلقائيًا الردهة التالية (`002` ثم `003`...).
- لا تُحذف الردهة عندما يصبح عدد لاعبيها صفرًا.
- العالم والبناء والموارد وتقدم اللاعب محفوظة بشكل مستقل لكل ردهة.
- يمكن البحث عن طريق رقم الردهة أو اسمها، وحفظ المفضلة في واجهة اللعبة.
- لا يمكن للاعب إنشاء ردهة من داخل اللعبة.

## التشغيل والنشر
`npm start` — المنفذ الافتراضي 8080، وWebSocket على `/ws`.

## متغيرات البيئة
- `PORT`: منفذ الخادم (8080 افتراضيًا).
- `DATA_DIR`: مسار ملفات البيانات (افتراضيًا `data` بجوار المشروع).
- `MAX_PLAYERS`: السعة لكل ردهة (20 افتراضيًا).
- `MAX_LOBBIES`: سقف تشغيلي (10000 افتراضيًا).
- `RESEND_API_KEY`, `EMAIL_FROM`: إرسال رمز تأكيد البريد.
- `ADMIN_API_KEY`: حماية لوحة الإدارة الخارجية.

## التخزين الدائم
اربط Volume دائمًا إلى `/app/data` على الاستضافة، وإلا قد تضيع الحسابات والعوالم والردهـات عند إعادة إنشاء الحاوية.

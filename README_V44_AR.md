# ISLAND SURVIVAL V44 — إصلاح تشغيل السيرفر والاتصال الجماعي

## ما تم إصلاحه
- تسجيل وإنشاء الحساب باسم المستخدم وكلمة المرور فقط؛ لا يعتمد إنشاء الحساب على Resend أو البريد الإلكتروني. الحسابات القديمة التي أُنشئت بإصدار OTP تظل قابلة للدخول بكلمة المرور.
- عنوان WebSocket الافتراضي أصبح من نفس نطاق الموقع وعلى المسار `/ws`، فلا يضيف المنفذ 8080 خطأً عند النشر خلف HTTPS/Reverse Proxy.
- تصحيح عنصر حالة الردهة في الواجهة (`data-st`) الذي كان يسبب خطأ JavaScript عند رسم قائمة السيرفرات.
- إذا امتلأت الردهة بين تحديث القائمة والاتصال، يحوّل السيرفر اللاعب تلقائيًا إلى ردهة عامة متاحة أو ينشئ التالية.
- حفظ JSON بطريقة ذرية (ملف مؤقت ثم rename) لتقليل تلف ملفات الحسابات والعوالم عند إعادة التشغيل.
- حفظ فوري لحقيبة اللاعب وتقدم القصة، مع حفظ دوري للعوالم.
- دعم الغرف الخاصة ونوع الإبداع من لوحة الإدارة، وفحص صحة يعرض عدد الاتصالات ووقت التشغيل.
- Ping/Pong دوري لتنظيف اتصالات WebSocket الميتة.

## التشغيل
يتطلب Node.js 18 أو أحدث.

```bash
npm start
```

افتح `http://localhost:8080`. لا تفتح `public/index.html` كملف محلي إذا أردت اللعب الجماعي؛ افتح الصفحة من عنوان السيرفر نفسه حتى تعمل واجهات API وWebSocket من نفس النطاق.

## فحص سريع
```bash
npm run check
npm test
```

## النشر
- Start command: `npm start`
- يجب أن تدعم الاستضافة Node.js وWebSocket وتوجّه HTTP وUpgrade إلى نفس الخدمة والمنفذ الذي تحدده `PORT`.
- اضبط `DATA_DIR` على مجلد دائم mounted volume. مثال: `/app/data`. إذا كانت الاستضافة تحذف ملفات الحاوية عند إعادة النشر ولم تربط تخزينًا دائمًا، فالحسابات والعوالم قد تضيع مهما كان الكود صحيحًا.
- إذا كانت اللعبة على نفس خدمة Node، اترك عنوان الخادم في الواجهة فارغًا/افتراضيًا؛ ستستخدم تلقائيًا `wss://نطاقك/ws` عند HTTPS.
- لا تضع `ADMIN_API_KEY` داخل ملفات الواجهة أو تشاركه مع اللاعبين.

## نقاط مهمة
- الحد الافتراضي 20 لاعبًا لكل ردهة عامة. عند الامتلاء يتم إنشاء ردهة جديدة تلقائيًا.
- جلسات الدخول صالحة 7 أيام في ذاكرة السيرفر؛ بعد إعادة تشغيل السيرفر قد يحتاج اللاعب إلى تسجيل الدخول مرة أخرى، لكن الحسابات والحفظ تظل في `DATA_DIR`.
- هذا الإصدار لا يحوّل تلقائيًا خدمة استضافة غير داعمة لـWebSocket أو تخزين دائم إلى خدمة داعمة؛ يجب تفعيل هذه الميزات من لوحة الاستضافة.
